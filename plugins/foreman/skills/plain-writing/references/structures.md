# Structures to avoid

Adapted from stop-slop by Hardik Pandya (MIT licence, see ../LICENSE).

## Binary contrasts

False drama. State the point directly.

| Pattern | Problem |
|---|---|
| "Not because X. Because Y." | Telegraphed reversal |
| "[X] isn't the problem. [Y] is." | Formulaic reframe |
| "The answer isn't X. It's Y." | Predictable pivot |
| "Not X, it's Y" / "isn't X, it's Y" | Mechanical contrast |
| "It's not just X, it's also Y" | Additive hedge |
| "stops being X and becomes Y" | False transformation |

**Instead:** "The problem is Y." Drop the negation.

## Negative listing

Listing what something is not before saying what it is.

| Pattern | Problem |
|---|---|
| "Not a X. Not a Y. A Z." | Build-up through negation |
| "It wasn't X. It wasn't Y. It was Z." | Same, past tense |

**Instead:** state Z.

## Dramatic fragments

Fragments for emphasis read as manufactured.

| Pattern | Problem |
|---|---|
| "[Noun]. That's it. That's the [thing]." | Performed simplicity |
| "X. And Y. And Z." | Staccato drama |

**Instead:** complete sentences.

## Rhetorical setups

These announce a point instead of making it.

| Pattern | Problem |
|---|---|
| "What if [reframe]?" | Posturing |
| "Here's what I mean:" | Redundant preview |
| "Think about it:" | Condescending |
| "The good news?" / "The bottom line?" | Question answered by the next word |

**Instead:** make the point.

## Things doing people's jobs

Inanimate things given human verbs, which hides who acted.

| Pattern | Fix |
|---|---|
| "The inspection revealed" | "We found" |
| "The data shows" | "The load readings show" or "We measured" |
| "The schedule slipped" | "The drywall crew finished a week late" |
| "A decision was reached" | "The owner decided" |
| "The project delivers" | "We installed" |

**Instead:** name the person or company. If no one specific fits, "we" usually works in his writing.

## Passive voice

Hides the actor and drains energy. In reports, passive is acceptable when the actor is unknown or
irrelevant ("the panel was installed around 1980"). Otherwise:

| Pattern | Fix |
|---|---|
| "The breaker was replaced" | "We replaced the breaker" |
| "It is recommended that" | "We recommend" |
| "Approval is required before" | "We need your written approval before" |

## Sentence starters to watch

| Pattern | Fix |
|---|---|
| Several Wh- openers in a row (What, When, Which, How) | Vary; lead with the subject. One is fine. |
| Paragraphs starting with "So" | Start with the content |
| Sentences starting with "Look," | Remove |

## Rhythm

| Pattern | Fix |
|---|---|
| Everything in threes | Use two, or one, or four if there are four |
| Question answered immediately | Cut the question |
| Every paragraph ending on a punchline | Vary the endings |
| A dash in every other sentence | One or two per document |
| Stacked short punchy sentences | Join some up |

## Word patterns

| Pattern | Problem |
|---|---|
| Sweeping words (every, always, never, nobody) doing vague work | False authority. Use the specific case. |
| Filler adverbs (really, just, actually, simply) | Empty emphasis. See phrases.md. |
